# 🛡️ KidShield - Smart Parental Screen Time & Safe Lock

KidShield is an Android parental control app designed with **Jetpack Compose** and **Material 3**. It naturally helps parents manage screen time by simulating realistic device states (Dead Battery, High Temperature, Offline Dinosaur) instead of frustrating confrontations.

---

## 🌟 Key Features
- 🔋 **Dead Battery Simulation**: Realistic drained battery warning.
- ⚠️ **Overheat Alert**: Fake system thermal warning.
- 🌐 **No Internet Mode**: Chrome offline dinosaur simulation.
- ⏱️ **Flexible Timers**: 1m, 5m, 10m, 15m presets and custom time.
- 🔐 **Long-Press Security**: Parents can set hold duration (2s to 10s) to prevent kids from bypassing.
- 👑 **KidShield Pro (Freemium)**: In-app direct UPI payment (Zero commission) to unlock 100% Ad-Free experience.

---

## 🛠️ Tech Stack
- Kotlin 2.3 + Jetpack Compose
- Target SDK 36, Min SDK 24
- Foreground Service with Audio Focus Management
- Window Manager Overlay (`SYSTEM_ALERT_WINDOW`)

---

## 📄 Privacy Policy
KidShield respects family privacy. It does not collect, transmit, or sell any personal data or usage logs. Everything runs locally on device.
